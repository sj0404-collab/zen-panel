1. KILO CODE GATEWAY  (самый удобный: 200 req/ч без ключа)
---------------------------------------------------------------------
Base URL: https://api.kilo.ai/api/gateway/v1
Пакет:   290 моделей, ~20 помечены :free
Лимит:   200 запросов/час на IP (бесплатно)

Модели с поддержкой изображений (vision):
  [✔] stepfun/step-3.7-flash:free
        текст + изображения; выводит reasoning (думает вслух).
  [✔] nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free
        мультимодальная: текст + изображения + аудио.
  [✔] dots-studio/dots-3-note-preview:free
        принимает изображения.
  [✔] inclusionai/ling-3.0-flash-vl:free
        принимает изображения (иногда 429 «server overload» — повторить).
  [✔] nex-agi/nex-n2.5-pro:free
        принимает изображения.
  [✔] inclusionai/ling-3.0-flash-sante:free
        отвечает на изображение (имеет vision; уточнено в запросе).

Только текст (без vision) из :free пула:
  nvidia/nemotron-3-super-120b-a12b:free
  nvidia/nemotron-3-ultra-550b-a55b:free
  nvidia/nemotron-3.5-lightning:free
  qwen/qwen3.8-27b:free
  z-ai/glm-5.2:free                (на изображение НЕ отвечает — 404)
  poolside/laguna-s-2.1:free
  cohere/north-mini-code:free
  liquid/lfm-2.5-2.6b:free
  thinkingmachines/inkling-small:free
  dots-studio/dots-3-note-preview:free (см. выше — vision есть)

Пример запроса (Python):
  import requests
  data_url = "data:image/jpeg;base64,...."
  r = requests.post("https://api.kilo.ai/api/gateway/v1/chat/completions", json={
      "model": "stepfun/step-3.7-flash:free",
      "messages": [{"role":"user","content":[
          {"type":"text","text":"Опиши фото"},
          {"type":"image_url","image_url":{"url":data_url}}]}],
      "max_tokens": 3000   # шаблону нужен запас: большой ход уходит в reasoning
  })
  print(r.json()["choices"][0]["message"]["content"])

Пример (curl):
  curl https://api.kilo.ai/api/gateway/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{"model":"stepfun/step-3.7-flash:free","messages":[{"role":"user","content":[{"type":"text","text":"Опиши фото"},{"type":"image_url","image_url":{"url":"data:image/jpeg;base64,..."}}]}],"max_tokens":3000}'

3. LLM7.IO  (аноним, но ТОЛЬКО ТЕКСТ)
---------------------------------------------------------------------
Base URL: https://api.llm7.io/v1
Лимит (аноним): 1 RPS, 10 RPM, 60 req/ч.
Важно: анонимно доступны НЕ все модели каталога (48 шт), а только
"turbo"-пул. Модели типа gemini-3-flash / grok-4.5 / gemma4:31b
отвечают БЕЗ ключа, но:
  "does not support vision input" — картинки НЕ принимают.
Часть моделей (gemini-3.1-flash-lite, gpt-5.6-luna, claude-*) отвечают
401 «Missing API key» — им нужен бесплатный токен с token.llm7.io.

Доступные анонимно (текст):
  gemini-3-flash, gemini-omni-flash (только специализ. endpoint),
  grok-4.5, gemma4:31b  — работают без ключа.
