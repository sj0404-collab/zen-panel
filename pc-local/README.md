# Zen Panel на локальном ПК

Две версии — обе без привязки к облачным раннерам GitHub:

| | Без раннера (этот каталог) | С раннером (`runner/`) |
|---|---|---|
| Что стартует | npm-hub + десктопная панель на этом ПК | то же + self-hosted Actions-раннер |
| Сессии | хаб локальный; агент/OpenCode/столы — по-прежнему в облаке GitHub | запуски из панели могут выполняться прямо на этом ПК |
| Нужно | Node.js 20+ | + одноразовый registration token из настроек репо |

## Без раннера

```bash
pc-local/start.sh        # Linux/macOS
pc-local\start.bat       # Windows
```

Скрипт проверит Node, в первый раз сделает `npm ci` для хаба, поднимет
хаб (`:8090`, `PORT=...` для смены) и откроет десктопную панель, если её
зависимости уже стоят (`cd desktop && npm install`). Адреса те же:

- хаб: `http://localhost:8090/`
- десктоп: `http://localhost:8090/d`
- мобильный: `http://localhost:8090/m` (с телефона в том же LAN — по IP этого ПК)

Остановка: `pc-local/stop.sh` / `pc-local\stop.bat`.

## С раннером

Каталог `runner/` — регистрация этого ПК как self-hosted раннера репозитория.
После неё в диалоге запуска панели появляется выбор «свой ПК», и агент,
OpenCode, хаб и столы выполняются локально. Подробности — в
[`runner/README.md`](runner/README.md).
